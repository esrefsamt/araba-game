# Phase 7 — Session / room sağlamlaştırma

Yalnız Phase 7 uygulandı. Phase 8 başlatılmadı. Commit, reset veya rebase yapılmadı. Çalışmaya başlarken mevcut Phase 6–6.2 değişiklikleri working tree içindeydi; korundular. Aşağıdaki tarayıcı sonuçları ajan tarafından yapılan kontrollerdir; kullanıcı tarafından verilmiş yeni bir manuel onay sayılmaz.

1. **Session token mimarisi.** Server `crypto.randomBytes(32)` ile 256-bit, 64 karakterlik hex capability üretir. `SessionRegistry` tokenı aktif connection, oyuncu ve oda ile ilişkilendirir. Player ID, room code, host veya skor iddiaları authentication yerine kullanılmaz. Tokenlar loglanmaz ve public player listesine girmez. Format doğrulaması ve 16 KiB WebSocket payload sınırı vardır.

2. **Client storage.** Token endpoint adresine göre ayrılmış browser `sessionStorage` içinde tutulur; storage erişilemezse memory fallback kullanılır. Yeni socket'in geçici welcome tokenı eski resume tokenını ezmez. Kalıcı login/account veya database eklenmedi.

3. **Grace süresi.** Varsayılan 15 saniye; `SESSION_GRACE_MS` ile ayarlanır. Unexpected disconnect oyuncuyu `DISCONNECTED_GRACE` durumuna geçirir. Merkezi server sweep yaklaşık saniyede bir expiry cleanup yapar; reconnect isteğinde deadline ayrıca doğrudan kontrol edilir. Oyuncu başına interval yoktur.

4. **Disconnect sırasında araç.** Aynı authoritative Rapier body grace boyunca kalır. Mevcut control-disable yoluyla throttle/brake/steering sıfırlanır, handbrake kapanır. Brake=0 seçimi mevcut reverse davranışını tetiklemez. Body mevcut fiziğe göre hareket edebilir; yeni body veya reconnect respawn oluşturulmaz. Eski socket'ten kuyruğa girmiş inputlar kabul edilmez.

5. **Disconnect sırasında scoring.** Scoring eligibility ve contact grace anında durur; current streak kesilir. Accumulated trailer ticks, best streak ve session points korunur. Devam eden round'a dönünce kontrol ve gerçek trailer temasından scoring yeniden mümkün olur. Ranking, puan tablosu, normal trailer scoring algoritması ve round süresi değiştirilmedi.

6. **Reconnect protocol.** Typed `reconnect_session { sessionToken }` isteği; typed `session_resumed { sessionToken, roomId, playerId, state }` yanıtı vardır. Token formatı, registry membership, deadline, room membership ve aktif socket sahipliği doğrulanır. `leave_room` hemen membership/body temizler ve `room_left` yeni, odaya bağlı olmayan token verir; eski token geçersizleşir.

7. **Full resync içeriği.** Resume state, düzenli broadcast ile aynı `GameRoom.createWorldSnapshot()` kaynağından gelir: server tick, bütün araçlar ve local authoritative metadata/lastProcessedInputSequence, convoy transform/path state, host, phase, round, timer, player scoreboard/ready/participant/connection states, sonuçlar ve session points. Odaya katılmamış session için oda/oyuncu/state null'dır. Transient RAM event geçmişi içermez.

8. **Prediction reset.** Kopmada gameplay input kapanır ve discontinuity hazırlığı yapılır. Resume'da World clear/resync eski interpolation/snapshot/prediction input bufferlarını ve vehicle views'i temizler; authoritative snapshot uygulanır ve mevcut prediction proxy authoritative state'ten initialize edilir. InputTransmitter server acknowledgement baseline'ından sonraki sequence ile devam eder. Transport generation guard eski latency/jitter timerlarını ve inputları düşürür; RAM feedback temizlenir. Prediction driving algoritması/tuning değiştirilmedi.

9. **Host policy.** Host disconnect anında en eski bağlı oyuncuya migrate edilir. Geri dönen eski host yetkiyi geri almaz; full snapshot mevcut doğru host'u gösterir. Herkes offline ise host null olur, ilk dönen oyuncuyla tekrar seçilir. Lobby start kontrolü bağlı oyuncuların readiness'ini kullanır; offline grace oyuncusu odayı kilitlemez. RESULTS next round aynı host policy'yi kullanır.

10. **Duplicate policy.** Sağlıklı aktif socket varsa yeni claim `SESSION_ACTIVE` ile reddedilir. Kapalı veya heartbeat timeout'a ulaşmış socket detach/terminate edilip meşru resume'a izin verilir. Player/vehicle sayısı değişmez; iki socket aynı oyuncuya input gönderemez.

11. **Heartbeat.** Varsayılan native server ping 5 saniye, receive timeout 15 saniye. Browser native pong'u otomatik gönderir. Pong veya normal client trafiği receive saatini yeniler; tek geciken paket disconnect üretmez. Mevcut application ping/pong latency ölçümü korunur. Client receive watchdog da varsayılan 15 saniyedir.

12. **Automatic reconnect.** Açık states: DISCONNECTED, CONNECTING, CONNECTED, RECONNECTING, FAILED. Backoff 0,5 / 1 / 2 / 3 / 5 saniye; üst sınır 5 saniye ve toplam süre grace window ile sınırlıdır. Explicit leave, token rejection, room loss, deadline ve açık server rejection denemeleri durdurur. Initial handshake timeout da sınırlıdır. Join/create/resume/leave için connection başına 10 saniyede 6 action guard eklenmiştir; mevcut input guard korunmuştur.

13. **Page refresh sonucu — A / lobby.** İki browser ile refresh edildi. Aynı room `6Y4J5D`, aynı player ID ve READY korundu; listede iki oyuncu kaldı. Refresh sırasında host peer'a migrate oldu ve dönüşte doğru host gösterildi. Beş saniyelik lobby disconnect de aynı kimliğe döndü. RECONNECTING overlay ve RECONNECTED feedback görüldü.

14. **Playing reconnect sonucu — B/C/I.** Değiştirilmemiş 90 saniyelik round'da 150 ms artificial latency ve ±20 ms jitter ile 5 saniyelik transport kopması denendi. 4,3 saniyelik trailer skoru korundu; peer scoreboard'da grace oyuncusu RECONNECTING olarak kaldı. Dönüşte aynı player/room, iki scoreboard entry ve `PREDICTION · 1 writes · 0 conflicts` görüldü. Otomatik test ayrıca aynı Rapier body'yi, korunmuş session points'i, scoring freeze'i, boş stale input history'yi ve sequence 42 → 43 devamını doğrular. Bu kontrol uzun süreli kullanıcı sürüş değerlendirmesinin yerine geçmez.

15. **Grace expiry sonucu — D.** DEV 16-second disconnect düğmesiyle denendi. Client 15 saniyelik deneme penceresi dolunca FAILED / Session expired ekranı ve RETURN TO LOBBY gösterdi; old room/player UI temizlendi. Testler expiry'de player/body/token cleanup, boş room removal ve slot açılmasını doğrular. Intentional leave ayrıca anında temizlenir.

16. **Results reconnect sonucu — F.** RESULTS refresh sonrası aynı ROUND 1 RESULTS, 4,3 / 0,0 trailer saniyesi, +10 / +7 round puanı ve 10 / 7 session puanı geri geldi. Results rows refresh öncesi/sonrası eşitti. HUD testleri restored RESULTS için round_end sesini, restored PLAYING/COUNTDOWN için mevcut GO/countdown cue'sunu tekrar üretmediğini doğrular.

17. **Room full / grace sonucu — G.** İki browser ve altı gerçek Node WebSocket client ile sekiz slot dolduruldu. Sekizinci client unexpected terminate edildi; grace boyunca health players=8 ve dokuzuncu browser JOIN sonucu anlaşılır ROOM FULL oldu. Expiry sonrası aynı dokuzuncu browser katılabildi. Unit test ayrıca body cleanup ve tam kapasite sınırını kontrol eder. Collision testi aynı room code üretimini mevcut odayı ezmeden yeniden üretir.

18. **Server restart sonucu — H.** Gerçek test server process durdurulup yeniden açıldı. Browser önce RECONNECTING, ardından Session expired or server restarted mesajı gösterdi. RETURN TO LOBBY yeni session'la bağlantıyı geri getirdi; eski room yoktu. Real TCP integration test restart sonrası eski tokenın SESSION_EXPIRED ile reddini ve boş health counts'u doğrular. İdempotent graceful stop testi socket close code=1001, HTTP listener cleanup ve tekrar stop güvenliğini doğrular; main SIGINT/SIGTERM bu stop yolunu kullanır.

19. **Production config.** Client `VITE_WS_URL`; server `PORT`, `HOST`, `NODE_ENV`, grace/heartbeat/shutdown environment değerleri desteklenir. HTTPS fallback wss, HTTP fallback ws; production aynı page host'u kullanır, development port 3000'i kullanır. HTTPS üzerinde ws override reddedilir. Client `.env.example`, server `.env.example` ve README deployment talimatları eklendi. TLS hosting/reverse proxy'de terminate edilir; gerçek dış ortam TLS deployment yapılmadı. Hem default build hem `VITE_WS_URL=ws://localhost:3000/` build geçti. Production static preview HTTP 200 verdi; mevcut preview sekmesi internal data error sayfasında kaldığı ve browser URL politikası kontrolü engellediği için production browser smoke tamamlanamadı. Development browser senaryoları tamamlandı; production URL ve debug-visibility testleri geçti.

20. **Health endpoint.** Aynı HTTP/WS portunda `GET /health`: status, rooms, players, process uptime saniyesi; Cache-Control=no-store. Grace slotları player sayısına dahildir. Çalışan server'da boş ve sekiz oyunculu durumlar gözlendi; integration testi token sızmadığını ve diğer path için 404'ü doğrular. Shutdown sırasında upgrade kabulü kapanır, simülasyon durur, socketler kapatılır; varsayılan 5 saniye deadline sonrası kalan transportlar terminate edilir, room/physics world dispose edilir.
